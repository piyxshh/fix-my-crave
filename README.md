# Fix My Craving 🍫

A modern web application designed to help users find healthy alternatives to their food cravings. Built with React, Vite, and Tailwind CSS, featuring beautiful animations and a user-friendly interface.

## Features 🌟

- **Smart Craving Detection**: Input your craving and get personalized healthy alternatives
- **Healthy Alternatives**: Detailed recipes and substitutes for common cravings including:
  - Chocolate cravings
  - Ice cream alternatives
  - Soda substitutes
  - Healthy french fry options
  - Pizza alternatives
  - Fried chicken substitutes
  - Cake and donut alternatives

- **Interactive UI**: 
  - Smooth animations using Framer Motion
  - Responsive design for all devices
  - Beautiful gradient effects
  - Floating food icons

## Tech Stack 💻

- React 18
- Vite 4
- Tailwind CSS
- Framer Motion
- ESLint for code quality

## Getting Started 🚀

### Prerequisites

- Node.js (version 14 or higher)
- npm (comes with Node.js)

### Installation

1. Clone the repository:
```bash
git clone [your-repo-url]
cd Fix-My-Crave
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and visit `http://localhost:5173`

## Usage 📝

1. Open the application in your browser
2. Click on "Fix My Craving" to start
3. Enter your current craving in the input field
4. Browse through the healthy alternatives provided
5. Click on any alternative to view detailed recipe instructions
